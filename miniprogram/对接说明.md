# 叶哲 STUDIO 微信原生小程序 · 对接说明

> 纯 C 端小程序（**不使用 web-view**）。商家全部管理操作在网页后台 `https://yezhe.netlify.app` 完成；小程序只做浏览 / 预约 / 选片 / 成片 / 评价。三者共用同一套后端 + 数据库，数据双向实时同步。

---

## 一、架构

```
微信原生小程序  ──HTTPS──▶  Render 后端(Express，与商家后台同一套代码/数据库)
                                      │
                                      ▼
                            Neon Postgres（生产）/ 本地 SQLite（开发）
                                      ▲
                                      │ 同一套 REST 接口
                                      │
商家 Web 后台 (https://yezhe.netlify.app)  ──管理全部数据──▶  同库
```

- 小程序与商家后台**调用不同的接口前缀**：
  - 小程序公开/客户接口：`/api/works/public`、`/api/packages/public`、`/api/wx/*`、`/api/customer/*`
  - 商家内部接口（小程序**禁止调用**）：`/api/schedules`、`/api/finance`、`/api/orders` 写操作、`/api/orders` 批量导出等
- 客户身份 = 后端签发的 **客户 token**（JWT，payload 仅含 openid + customerId，无法冒充商家角色）。

## 二、目录结构（miniprogram/）

```
app.js              全局 wx.login → /api/wx/login 换 openid + 客户 token，缓存本地
app.json            4 个 tabBar（首页/作品/套餐/我的）+ 10 页面注册
app.wxss            黑白简约摄影风全局样式
config.js           ★API_BASE 改成你的 Render https 域名；WEB_ADMIN 商家后台
utils/req.js        带鉴权的请求封装（/api/customer/* 自动登录并带 token）
pages/
  index/            首页（精选客片 / 套系 / 客户评价 / 大图弹层）
  works/            作品（分类筛选 + 瀑布网格 + 大图弹层）
  package/          套餐（列表 + 详情 + 立即预约）
  my/               我的（预约/订单/评价入口 + 联系/后台）
  appointment/      预约（表单 + 我的预约列表）
  order/            订单（列表 + 详情弹层 + 跳成片/选片/评价）
  photoSelect/      在线选片（勾选小样 + 保存草稿 / 提交）
  album/            成片相册（浏览 + 保存到相册，受 allow_download 控制）
  evaluate/         评价（星级 + 文本提交 + 我的评价）
  subscribe/        订阅消息提醒（可选）
```

## 三、后端接口清单（小程序侧）

### 公开（无需登录）
| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/works/public?category=&q=&page=&pageSize=` | 公开作品列表（仅 `is_public=1`） |
| GET | `/api/works/public/:id` | 作品详情（相册**仅返 sample/final 小样**，绝不返 local 原片） |
| GET | `/api/packages/public` | 公开套系列表（仅 `status='on'`） |
| GET | `/api/packages/public/:id` | 套系详情 |
| GET | `/api/customer/evaluate/public` | 已审核通过的好评墙（首页展示） |
| GET | `/api/categories` | 作品分类（用于筛选） |

### 登录
| 方法 | 路径 | 说明 |
|---|---|---|
| POST | `/api/wx/login` `{code}` | 返回 `{openid, customerId, token}`，`app.js` 自动完成 |

### 客户接口（需 `Authorization: Bearer <token>`，按 openid 行级隔离）
| 方法 | 路径 | 说明 |
|---|---|---|
| POST | `/api/customer/appointment/submit` `{name,phone,packageId,hopeDate,remark}` | 提交预约 |
| GET  | `/api/customer/appointment/list` | 我的预约 |
| GET  | `/api/customer/order/list` | 我的订单（只返绑定自己 openid 的） |
| GET  | `/api/customer/order/:orderId` | 订单详情（越权 → 403） |
| GET  | `/api/customer/album/:orderId` | 成片相册（只返小样；越权 → 403） |
| POST | `/api/customer/photo-select/save` `{orderId,marks}` | 保存选片草稿 |
| POST | `/api/customer/photo-select/submit` `{orderId,marks}` | 提交选片 |
| GET  | `/api/customer/photo-select/:orderId` | 读取我的选片 + 可勾选小样 |
| POST | `/api/customer/evaluate/submit` `{orderId,stars,text,images}` | 提交评价 |
| GET  | `/api/customer/evaluate/list` | 我的评价 |

### 可选
| 方法 | 路径 | 说明 |
|---|---|---|
| POST | `/api/wx/subscribe-msg` `{openid,templateId,data}` | 记录订阅意图（真实下发由服务端用 access_token 调微信） |

## 四、微信公众平台配置

1. **request 合法域名**：开发管理 → 开发设置 → 服务器域名 → **request 合法域名** 添加 `https://<你的render域名>`。成片保存用到 `downloadFile` 合法域名，也需添加。
2. **AppSecret**：`WX_SECRET` 仅存在于后端 Render 环境变量，**绝不下发前端**。前端只持有 `code`（一次性）+ 后端签发的 token。
3. **环境变量（Render）**：`WX_APPID`、`WX_SECRET`、`DATABASE_URL`(Neon)、`JWT_SECRET`、`CORS_ORIGIN=https://yezhe.netlify.app`、`FRONTEND_WEB=https://yezhe.netlify.app`。`WX_APPID/SECRET` 留空时 `code→openid` 返回 `DEBUG_<code>`，开发可联调。

---

## 五、安全边界（强制）

- **openid 不可信**：客户 token 由后端签发，行级隔离以 token 中的 openid 为准，不信任客户端传入的 openid。
- **越权拦截**：访问他人 `orderId` / 相册 / 选片 → **403**；未带 token → **401**。
- **小样隔离**：作品/成片接口只返回 `sample`/`final` 分区，绝不返回 `local` 原片分区。
- **最小暴露**：小程序不暴露档期、财务、新建订单、批量导出等商家接口。
- **成片下载开关**：`works.allow_download=1` 时相册页才显示「保存」按钮。

## 六、上线前必测 6 项

1. 后台新增作品（公开）→ 小程序首页/作品页可见。
2. 后台上架套系 → 小程序套餐页可见。
3. 小程序提交预约 → 后台 `appointments` 可见。
4. 后台为某客户建订单并绑定其 openid → 同微信小程序「我的订单」可见。
5. 小程序在线选片提交 → 后台该订单选片结果可见 / 可改。
6. 小程序提交评价 → 后台审核流转（pending→approved 后出现在首页好评墙）；成片权限 + 越权访问他人订单返回 403。

## 七、本地联调 / 发布步骤

1. 后端按 `README.md` 第三~四节部署到 Render（接 Neon）；开发期可本地 `node server/src/index.js`（SQLite）。
2. 改 `miniprogram/utils/config.js` 的 `API_BASE` 为 Render https 域名（本地联调填局域网 `http://<Mac IP>:4000`，但需注意微信 request 域名校验，开发工具可勾选「不校验合法域名」）。
3. 微信开发者工具导入 `miniprogram/`，填真实 AppID（或测试用 `touristappid`），勾选「不校验合法域名、web-view、TLS 版本」便于联调。
4. 正式发布：在小程序后台配置 request 合法域名 + 真实 AppID，取消「不校验」选项，上传并提审。
